# เอกสารอ้างอิงสำหรับทำงานต่อ

สำเนาวิกิซอร์ซ 100 บทใน `zh.wikisource/封神演義/` เก็บใน Git พร้อมลิงก์รุ่นแก้ไขและ SHA-256 เดิมใน `sources.json` จึงใช้ฉบับเดียวกับที่อ้างอิงระหว่างแปล ไม่ดึงรุ่นปัจจุบันมาแทน

PDF ฉบับพิมพ์หมิง 舒文淵 20 เล่ม เก็บเป็นไฟล์แนบของ [GitHub Release sources-v1](https://github.com/pongcool/fengshen/releases/tag/sources-v1) และดาวน์โหลดลง `najda/` โดยไม่เก็บไฟล์ PDF ใน Git ทะเบียนชื่อไฟล์ ขนาด และ SHA-256 อยู่ใน `najda/manifest.json` เล่ม N ครอบคลุมบท 5N−4 ถึง 5N

## เตรียมเครื่องใหม่

ต้องมี Python 3.9 ขึ้นไป, Git และ [GitHub CLI](https://cli.github.com/) เนื่องจาก repository เป็น private บัญชี GitHub ต้องได้รับสิทธิ์เข้าถึง `pongcool/fengshen`

```powershell
gh auth login
gh repo clone pongcool/fengshen
cd fengshen
python -X utf8 tools/setup_sources.py
```

ถ้า clone ไว้แล้ว ให้รันคำสั่ง Python จากโฟลเดอร์โปรเจกต์ได้เลย สคริปต์ตรวจสำเนาวิกิซอร์ซและ PDF ด้วย SHA-256 ดาวน์โหลดเฉพาะ PDF ที่ขาดหรือไม่ตรงทะเบียน หากดาวน์โหลดขาดช่วง ให้รันคำสั่งเดิมซ้ำ ไฟล์เดิมจะถูกแทนที่เมื่อไฟล์ใหม่ผ่านการตรวจแล้วเท่านั้น

ตรวจไฟล์ทั้งหมดแบบออฟไลน์โดยไม่ดาวน์โหลดหรือแก้ไฟล์:

```powershell
python -X utf8 tools/setup_sources.py --check
```

ผลตรวจที่ครบคือ `Wikisource: 100/100 verified` และ `PDFs: 20/20 verified` หากสำเนาวิกิซอร์ซผิดจากทะเบียน สคริปต์จะหยุดให้ตรวจหรือกู้ไฟล์จาก Git แทนการเปลี่ยนเนื้อหาเอง

## ที่มาและการรักษาฉบับอ้างอิง

- วิกิซอร์ซ: ดู [รายละเอียดสำเนา](zh.wikisource/封神演義/README.md) และประวัติรุ่นแก้ไขใน `sources.json`
- ฉบับพิมพ์หมิง: 新刻鍾伯敬先生批評封神演義 ร้าน 金閶載陽舒文淵 หอจดหมายเหตุแห่งชาติญี่ปุ่น เลขที่ 附001-0003; สำเนาสแกนสาธารณสมบัติจาก [Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:新刻鍾伯敬先生批評封神演義)
