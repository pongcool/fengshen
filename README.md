# ห้องสิน — โปรเจกต์แปลไทย

แปล 封神演義 จากต้นฉบับจีนใน `chapters/` จำนวน 100 บท โดยรักษาเนื้อหา ลำดับเหตุการณ์ และน้ำเสียงของตัวละคร

## เริ่มงาน
1. อ่าน [แนวทางแปล](TRANSLATION_GUIDE.md), [ตัวอย่างสำนวน](docs/STYLE_SAMPLE.md), [ตารางถอดเสียง](docs/TRANSLITERATION.md) และ [สรรพนามและคำเรียก](docs/ADDRESS_TERMS.md)
2. ตรวจ [ศัพท์กลาง](GLOSSARY.md), [ตัวละคร](CHARACTERS.md), [โลกของเรื่อง](WORLD.md), [ข้อยุติ](DECISIONS.md) และ [ข้อสังเกตในต้นฉบับ](docs/SOURCE_ISSUES.md)
3. เลือกบทจาก [สถานะงาน](PROGRESS.md) อ่านต้นฉบับเต็มบท และคำแปลบทก่อนหน้าถ้ามี
4. แปลลง `translations/th/NNN.md` ใช้เลขสามหลักตรงกับต้นฉบับ เช่น `001.md`
5. เพิ่มศัพท์และข้อสงสัย รัน `python -X utf8 tools/check_translation.py NNN` ตรวจตามรายการในคู่มือ แล้วอัปเดตสถานะ

## โครงสร้าง
- `chapters/` — ต้นฉบับจีน ห้ามแก้เพื่อให้ตรงกับคำแปล
- `translations/th/` — คำแปลไทยที่เริ่มทำจริงเท่านั้น
- `reviews/` — บันทึกตรวจแต่ละบท ใช้ชื่อ `NNN.md`
- `docs/STYLE_SAMPLE.md` — ตัวอย่างสำนวนเบื้องต้น ยังไม่ใช่บทแปลที่ผ่านการรับรอง
- `docs/TRANSLITERATION.md` — ตารางถอดเสียงจีนกลางเป็นไทย
- `docs/ADDRESS_TERMS.md` — สรรพนามและคำเรียก
- `docs/SOURCE_ISSUES.md` — รูปแปร คำที่น่าจะพิมพ์ผิด และลักษณะของต้นฉบับ
- `tools/check_translation.py` — ตรวจหัวบท ป้ายย่อหน้า อักษรจีนหลง เชิงอรรถ และรูปที่ศัพท์กลางห้ามใช้
- `tools/check_terms.py` — ตรวจว่าคำแปลใช้รูปไทยตามศัพท์กลางเมื่อต้นฉบับมีคำนั้น
- `tools/term_stats.py` — นับคำจีนในต้นฉบับ ใช้ก่อนลงทะเบียนศัพท์ใหม่
- `tools/find_variants.py` — หาชื่อในต้นฉบับที่ต่างจากศัพท์กลางหนึ่งตัวอักษร
- `AGENTS.md` — ข้อกำหนดสำหรับ AI ที่ทำงานในโปรเจกต์นี้

## ค่าเริ่มต้น
ใช้ไทยร่วมสมัยมีกลิ่นอายพงศาวดาร ระดับภาษานี้เป็นค่าเริ่มต้นที่รอผู้ใช้ประเมิน
ชื่อเรื่องคง “ห้องสิน” (D002, D035) ระบบชื่อจีนกลาง (D007) ถูกยกเลิกตาม D035 และยังไม่กำหนดระบบแทน (O008) บทที่แปลแล้วยังใช้รูปจีนกลาง รูปที่ใช้ไม่ได้อ้างว่าเป็นชื่อมาตรฐานของฉบับแปลไทยเดิม ถ้าเปลี่ยนภายหลังต้องตรวจผลกระทบทุกบท

## สถานะตั้งต้น
สคริปต์ต้องใช้ Python 3 และเรียกด้วย `python -X utf8` บน Windows
จัดทำเอกสาร ตัวอย่างสำนวน ตารางถอดเสียง ตารางคำเรียก ศัพท์ลงทะเบียนล่วงหน้า และสคริปต์ตรวจแล้ว ยังไม่ได้แปลบทใดเต็มบท ขั้นต่อไปคือแปลบท 001 เป็นบทนำร่อง ตรวจต้นฉบับและภาษา แล้วให้ผู้ใช้ประเมินสำนวนก่อนขยายงาน
