# ตารางถอดเสียงจีนกลางเป็นไทย

ใช้กับชื่อเฉพาะทุกชื่อตามข้อยุติ D007 เพื่อให้พยางค์เดียวกันสะกดเหมือนกันทุกบท
ตารางนี้เป็นกติกาของโครงการ จัดให้สอดคล้องกับรูปที่ใช้แล้วในศัพท์กลาง (โจ้วหวัง, หนี่ว์วา, ต๋าจี่, เจียงจื่อหยา, เหวินจ้ง, เฉาเกอ, เป่ยไห่) ไม่ได้อ้างว่าตรงกับเกณฑ์ของหน่วยงานใดทุกข้อ

## ขั้นตอน
1. หาคำอ่านพินอินพร้อมวรรณยุกต์ของแต่ละตัว ระวังอักษรหลายเสียง เช่น 朝歌 อ่าน cháo, 南宮适 อ่าน kuò, 哪吒 อ่าน né, 番天印 อ่าน fān
2. แปลงพยัญชนะต้นและสระตามตารางด้านล่าง
3. ใส่วรรณยุกต์ตามกลุ่มอักษร
4. เขียนชื่อติดกันไม่เว้นวรรค รวมถึงยศหรือคำนำหน้าที่ติดชื่อ เช่น ไท่ซือเหวินจ้ง; ยศที่ถอดเสียงทั้งชุดให้เรียงตามต้นฉบับ (聞太師 = เหวินไท่ซือ, 太師聞仲 = ไท่ซือเหวินจ้ง, 聞太師仲 = เหวินไท่ซือจ้ง) ส่วนยศที่แปลเป็นไทยใช้ลำดับไทย (黃元帥 = แม่ทัพใหญ่หวง) ตาม D058
5. ค้นใน GLOSSARY.md ก่อนเสมอ ถ้ามีรูปอยู่แล้วให้ใช้รูปนั้น ถ้าเป็นชื่อใหม่ให้ลงทะเบียนพร้อมพินอินในช่องหมายเหตุ

## ตำแหน่งวรรณยุกต์
- วางรูปวรรณยุกต์บนพยัญชนะต้นตามอักขรวิธีไทย เมื่อมี ห นำ ให้วางบนตัวที่สอง เช่น หนี่ว์, เหล่า
- พยางค์ อวี วางรูปบน ว เช่น อวี้, อวี่
- ไม่ใส่วรรณยุกต์เพิ่มเพื่อให้ออกเสียงตามหูไทย ใช้ตามตารางเท่านั้น

## ส่วนของชื่อที่ถอดเสียงและส่วนที่แปล
ดูข้อยุติ D013 ใน DECISIONS.md โดยสรุปคือ
- ถอดเสียงเฉพาะส่วนที่เป็นชื่อ ส่วนที่บอกประเภทให้แปล เช่น 山 เขา, 關 ด่าน, 島 เกาะ, 洞 ถ้ำ, 宮 วัง/วิหาร, 臺 หอ, 樓 หอ, 水 (ชื่อแม่น้ำ) แม่น้ำ
- คำนำหน้าหรือคำท้ายที่ประกอบเป็นนามของเทพหรือผู้บำเพ็ญ ได้แก่ 真人, 真君, 天尊, 道人, 聖母, 教主, 子 ให้ถอดเสียงรวมกับชื่อ
- 娘娘 เป็นคำเรียก ให้แปลตาม docs/ADDRESS_TERMS.md
- ของวิเศษ ค่ายกล และวิชา ให้แปลความหมาย ถ้ามีชื่อเฉพาะอยู่ในนั้น ให้ถอดเสียงเฉพาะส่วนนั้น

## เมื่อกติกาให้รูปที่อ่านยาก
ห้ามแก้รูปเองในบทแปล ให้ใช้รูปตามตาราง แล้วบันทึกใน reviews/NNN.md และเปิดประเด็นใน DECISIONS.md ถ้าตัดสินใช้ข้อยกเว้น ต้องเพิ่มไว้ในตารางข้อยกเว้นข้างล่าง
