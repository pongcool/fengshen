# สรรพนามและคำเรียก

ค่าเริ่มต้นตามข้อยุติ D009 ใช้ทุกบท ห้ามเลือกคำเองตามความเคยชินของแต่ละบท
จำนวนครั้งและบทแรกนับจากต้นฉบับทั้ง 100 บทด้วย tools/term_stats.py เมื่อ 2026-10-30 เป็นการนับตัวอักษร จึงรวมกรณีที่ไม่ได้ใช้เป็นสรรพนามด้วย เช่น 孤 ที่แปลว่ากำพร้า หรือ 臣 ในคำว่า 群臣

## หลักตัดสิน
0. ถ้าต้นฉบับให้ตัวละครเรียกตัวเองด้วยชื่อ ให้ใช้ชื่อนั้นในคำแปล ไม่แปลงเป็นสรรพนาม และไม่ใช้ “ข้าพเจ้า” ซึ่งให้ความรู้สึกแบบนิยายไทยสมัยใหม่ (D026)
1. ดูผู้พูด ผู้ฟัง และฐานะในฉากก่อนดูคำจีน
2. พูดกับกษัตริย์หรือผู้ครองราชย์ ใช้แถว “ต่อกษัตริย์” เสมอ ไม่ว่าต้นฉบับใช้คำแทนตัวแบบใด
3. คู่สนทนาที่มีคำเรียกเฉพาะ ให้บันทึกใน CHARACTERS.md และใช้ตามนั้นทุกบท
4. ถ้าน้ำเสียงในฉากขัดกับค่าเริ่มต้น เช่น ด่าทอ เยาะเย้ย หรือแสร้งนอบน้อม ให้เลือกคำที่สื่อน้ำเสียงนั้น และบันทึกเหตุผลใน reviews/NNN.md

## คำบรรยายของผู้เล่า
- ผู้เล่าเรียกกษัตริย์ตามที่ต้นฉบับเรียก: 紂王 โจ้วหวัง, 天子 โอรสสวรรค์
- ผู้เล่าไม่ใช้ราชาศัพท์เต็มรูปทุกกริยา ใช้เฉพาะคำที่ทำให้ฐานะชัด เช่น เสด็จ, ตรัส, พระบัญชา
- ผู้เล่าใช้ “เขา/นาง” กับตัวละครที่ระบุชัดแล้ว ไม่ใช้ “มัน” เว้นแต่ต้นฉบับเหยียดหรือเป็นสัตว์
