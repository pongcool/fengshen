## การตัดสินระหว่างแปล
- ชื่อบท 殷郊岐山受犁鋤 → “อินเจียวรับเคราะห์ถูกไถและจอบที่เขาฉี” (犁鋤 ตามแถว 犁鋤之厄 บท 063)
- ย2 離地無旗孰可棲 → “ไร้ธงแห่งทิศหลีแล้วใครจะพึ่งพิงได้” อ่าน 離地 ตามชื่อธงในบท ขอผู้ตรวจดู
- ย3 氣化清風魂伴泥 → “ปราณกลายเป็นลมใส วิญญาณอยู่กับดินโคลน”
- ย6 離地 / 震地 / 坎地 ใช้ ทิศหลี / ทิศเจิ้น / ทิศข่าน; ชื่อธง 離地焰光旗 → “ธงเปลวแสงแห่งทิศหลี”
- ย10 非東南兩度之客 → “มิใช่แขกจากสองแดนตะวันออกและใต้”; 實三生有緣 → “นับเป็นวาสนาสามชาติแท้ ๆ”
- ย15 頂摩霄漢，脈插須彌 → “ยอดเสียดฟ้าสูง แนวเขาปักลึกถึงเขาซวีหมี” (ไม่เพิ่มเชิงอรรถซ้ำ 047-2)
- ย16 鳴鳳岐山 → “หงส์ร้องที่เขาฉี”; 仙臨殺戒，垂象上天 → “เหล่าเซียนถึงคราวข้อห้ามการฆ่า ฟ้าเบื้องบนแสดงลาง”
- ย18 毋得延緩，有褻仙寶 → “อย่าได้ชักช้า อันจะเป็นการหมิ่นของวิเศษแห่งเซียน”
