# เชิงอรรถตัวเลขแบบคูณ (D060)

- ผู้สั่ง: ผู้ใช้ 2026-11-23 “ถ้าเป็นคำแปลที่เกี่ยวกับการคูณตัวเลข ให้เพิ่มในเชิงอรรถไว้ด้วยว่าหมายถึงอะไร”
- ผู้ทำ: AI Claude
- สถานะ: รอตรวจอิสระ (Codex) ตาม D042

## ขอบเขต
ค้นคำแปลทุกบทด้วย “คูณ” และรูปท่องสูตรคูณ (สี่เจ็ด, สองแปด, สามสาม, เก้าเก้า ฯลฯ) แล้วเทียบกับจีน
- รวม: จุดที่คำแปลแสดงการคูณ (“ก คูณ ข” หรือรูปสูตรคูณ) ใส่เชิงอรรถที่จุดแรกของแต่ละบท
- ไม่รวม: ทวีคูณ (023, 053) ไม่ใช่ตัวเลขคูณ; สามห้า (สามห้าวัน/เพลงท่า) เป็นจำนวนโดยประมาณ; 三三兩兩 (030 ย9) แปลว่ากลุ่มละสองสาม; 二四年 (023 ย11) แปลเป็น “แปดปี” แล้ว (R023-2)

## ค้างรอผู้ใช้ตัดสิน (ยังไม่ใส่เชิงอรรถ)
คำต่อไปนี้มีตัวเลขที่อาจเป็นการคูณ แต่คำแปลไม่ได้แสดงเป็นรูปคูณ หรือความหมายไม่แน่ชัด
- 005 ย9 二八陰消 / 三九陽長 = “สองแปดหยินลดลง / สามเก้าหยางเพิ่มขึ้น” ศัพท์เล่นแร่แปรธาตุ (R003 ในบท 005)
- 050 ย3 九九曲 / 三三灣 = “คดเก้าเก้าคด / คุ้งสามสามคุ้ง”
- 097 ย10 三九重逢日 = “วันสามเก้าได้พบกันอีก” (ยังไม่ยุติว่าหมายถึงอะไร)
- 八九玄功 / 八九玄機 / 八九工夫 / 八九變化 = “วิชาลึกล้ำแปดเก้ารอบ” ฯลฯ (065 067 070 092) เป็น 八九 เดียวกับ 八九元功 แต่ใช้รูป “แปดเก้ารอบ” ไม่ใช่ “แปดคูณเก้า” ต้องแก้คำกลางก่อนจึงใส่เชิงอรรถแบบเดียวกันได้
