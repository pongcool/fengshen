## การตัดสินระหว่างแปล
- ชื่อบท 金吒智取游魂關 → “จินจาใช้อุบายยึดด่านโหยวหุน” 智取 = ยึดด้วยอุบาย
- ย2 徹地多謀弄女紅 → “เช่อตี้แม้มากอุบายก็ได้แต่เล่นงานเย็บปักของสตรี” อ่าน 女紅 ว่างานเย็บปัก (เสียดสีว่าอุบายของนางไม่เป็นผล) ความหมายวรรคยังไม่แน่ชัด
- ย3 王霸終歸主 → “อำนาจราชันย่อมคืนสู่ผู้เป็นเจ้า” 崆峒 → เขาคงถง ตามชื่อกลาง (ใช้เป็นภาพในกวี)
- ย6 任你精靈骨已穿 → “ต่อให้เจ้าเป็นภูตก็ถูกร้อยทะลุกระดูกแล้ว” แปลตามตัว
- ย11 天倫私怨 → “แค้นส่วนตัวในสายสัมพันธ์ของตน” 天倫 ปกติคือสายเลือด แต่ในฉากหมายถึงอาจารย์อา
- ย11 方外術士 → “นักเวทผู้ออกจากทางโลก”; ย13 綑綁手 → “พลมัดเชลย”
- ย16 金城 → “เมืองอันมั่นคง”; 專征 → “ถือสิทธิ์ยกทัพปราบ” (ตาม 得專征伐)
- ย19 虎眼鞭，龍尾半 → “แส้ตาเสือ ยาวราวครึ่งหางมังกร” ความหมาย 龍尾半 ไม่ชัด แปลตามตัว; 玲花獻 → “ประดับลายดอกไม้ฉลุ”
- ย20 將欲取之，必固與之 → “หากคิดจะเอาไป ย่อมต้องให้มาก่อน” (ภรรยาเตือนว่าการให้หม่าจ้าวมาอาจเป็นเหยื่อเพื่อเอาด่าน)
- ย20 徹地夫人 / 徹地娘子 → “นางเช่อตี้” ถือ 徹地 เป็นชื่อเรียก (กวี ย2 ใช้ 徹地 ลำพัง)
