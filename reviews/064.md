## การตัดสินระหว่างแปล
- ย2 配合干支在丙丁 → “จับคู่กับก้านฟ้ากิ่งดินอยู่ที่ปิ่งติง” เชิงอรรถ 064-1 (หลี = ไฟ, ปิ่งติง = คู่ก้านฟ้าธาตุไฟ อ้างเชิงอรรถ 058-1)
- ย3 不是羅宣能作難，只因西土降仙卿 → “มิใช่หลัวเซวียนจะก่อความยุ่งยากได้ เพียงเพราะแดนตะวันตกมีเซียนผู้สูงศักดิ์ลงมา” (仙卿 = หลงจี๋ ตามเนื้อเรื่อง ไม่ระบุในวรรค)
- ย4 終不然是吾弟自走入太極圖中去 → “หรือว่าน้องศิษย์เดินเข้าไปในแผนภาพไท่จี๋เอง” (คำถามประชด); 倘一時失體，不好看相 → “หากพลั้งเสียมารยาทไปชั่วขณะ จะดูไม่งาม”
- ย6 馬善不知他的本主等他 → “ไม่รู้ว่าเจ้าของเดิมของตนรออยู่” (本主 = หรานเติงเจ้าของตะเกียง); 數射之地 → “ระยะยิงธนูไม่กี่ช่วง”
- ย9 大戰龍潭虎穴 → “รบกันดุเดือดดั่งในถ้ำมังกรรังเสือ”
- ย11 楊戩一彈子 → “ยิงลูกกระสุนนัดหนึ่ง” (ตาม 金丸 ลูกกระสุนทอง); 翻觔斗 → “ตีลังกา”
- ย14 往下三路 → “ฟาดเข้าช่วงล่าง” (ถู่สิงซุนตัวเตี้ยตีส่วนล่าง); 萬鴉壺 → “คนโทหมื่นกา” (壺 ภาชนะมีปาก ไม่ใช้ น้ำเต้า ที่สงวนให้ 葫蘆); 萬里起雲煙 แปลชื่อตามความหมายโดยไม่เติมคำว่าศร เพราะ ย18 ผู้เล่าอธิบายว่าเป็น 火箭
- ย15 赤寶丹天 → “ฟ้าแดงชาดล้ำค่า”; 南極熬成 → “เคี่ยวจนสำเร็จที่ขั้วใต้” (ทิศใต้ = ไฟ) ขอผู้ตรวจดู
- ย19 熱油門上飄絲 → “น้ำมันร้อนที่ประตูพลิ้วเป็นเส้นไหม” แปลตามตัว ความหมายภาพไม่แน่ชัด ขอผู้ตรวจดู; 說甚麼燧人鑽木 → “ยังจะพูดอะไรถึงซุ่ยเหรินปั่นไม้ก่อไฟ”; 慌壞青鸞斗闕仙 → ทำให้เซียนแห่งหอโต่วนกหลวนเขียว (หลงจี๋) ตื่นตระหนก
- ย20 告祈后土、皇天 → “อธิษฐานต่อแม่ธรณีและฟ้าหลวง” ตาม 皇天后土 (017) ลำดับตามต้นฉบับ
- ย22 正中赤煙駒後臂 → “ถูกขาหลังของม้าควันแดง” (臂 ของสัตว์สี่เท้า = ขาหน้า/หลังตามคำขยาย); ข้อความแทรก ──火龍進入於海內，焉能濟事！ คงเป็นเสียงผู้เล่า
- ย26 เพลงไม่มีชื่อผู้ร้องในเพลง แปลเป็นบล็อกกวี ไม่ใส่เครื่องหมายคำพูด (เครื่องหมาย 「」 ในต้นฉบับครอบทั้งเพลง)
- ย12 紅發 อ่าน 紅髮 (รูปแปร 發/髮) แปล “ผมแดง”
